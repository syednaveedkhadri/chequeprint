# Cheque Printer

Browser-based cheque printing for Kuwaiti bank cheques (KWD). Fill in date, payee, amount and purpose; the app writes the amount in English or Arabic words and prints **only the text** onto your real bank-issued cheque leaf.

## Features
- Al Ahli Bank of Kuwait (ABK) template, 180 × 90 mm leaf
- Amount in words (English / Arabic), `#10,000#` amount padding
- Crossing: A/C Payee, A/C Payee Only, Not Negotiable, Cash only
- Drag / double-click fields to calibrate; printer X/Y offset
- Batch printing from Excel (CSV)
- Payment report with CSV export, backup / restore

## Use
Open `index.html` in Chrome, or enable GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`).
Print with scale **100%** / "Actual size" and margins **None**. Do a test print on plain paper first.

The cheque image is shown on screen for alignment only and is never printed.
